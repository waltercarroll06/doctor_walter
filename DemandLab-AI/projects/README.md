# Proyectos prácticos

Aquí crearás tus proyectos independientes de práctica. Cada proyecto tendrá su propia carpeta con un nombre descriptivo y su propio `README.md`.

Los ejercicios diarios van en `sessions/`. Por ejemplo, el [Día 1 — Fundamentos de análisis de datos](../sessions/dia_01_fundamentos_analisis_datos/README.md) tiene allí su archivo de código y su registro de aprendizaje.

## Cómo organizar un proyecto

Cuando comiences un proyecto con tu mentor:

1. Crea dentro de `projects/` una carpeta con un nombre que describa su objetivo, en minúsculas y con guiones bajos entre palabras.
2. Añade un `README.md` dentro de esa carpeta.
3. Describe en ese README el objetivo, el estado actual, los datos utilizados y cómo ejecutar el código cuando lo hayas desarrollado.
4. Registra tus aprendizajes, resultados, dificultades y conclusiones a medida que avances.
5. Añade únicamente los archivos necesarios para ese proyecto.

Ejemplo de organización futura (estas carpetas de ejemplo todavía no existen):

```text
projects/
├── README.md
└── nombre_descriptivo_del_proyecto/
    └── README.md
```

Todavía no hay proyectos implementados en esta carpeta. Los crearás de forma gradual, sin generar soluciones por adelantado.
